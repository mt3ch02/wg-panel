# Security policy / Polityka bezpieczeństwa

**EN.** wg-panel writes firewall rules and runs a small helper as root, so security reports matter. Please **do not open a public issue** for a vulnerability. Use GitHub's private reporting (Security → *Report a vulnerability*) on this repository. Include the version/commit, what you did, and what you expected. You'll get an answer as soon as the maintainers can; this is a hobby project, so there is no SLA.

Out of scope (documented limitations): root access on the Pi, physical access to the SD card, and exposing the panel to the public internet against the documentation's advice. wg-panel has **not** had an independent security audit.

**PL.** wg-panel zapisuje reguły firewalla i uruchamia małego helpera jako root, więc zgłoszenia dotyczące bezpieczeństwa są ważne. **Nie zakładaj publicznego issue** dla podatności. Skorzystaj z prywatnego zgłaszania na GitHubie (Security → *Report a vulnerability*). Podaj wersję/commit, co zrobiłeś i czego oczekiwałeś. Odpowiemy, gdy będziemy mogli; to projekt hobbystyczny, bez gwarantowanego czasu odpowiedzi.

Poza zakresem (opisane ograniczenia): root na Pi, fizyczny dostęp do karty SD oraz wystawienie panelu do internetu wbrew dokumentacji. wg-panel **nie** przeszedł niezależnego audytu bezpieczeństwa.
